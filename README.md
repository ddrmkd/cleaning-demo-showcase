# FORMACLEAN — интерактивный калькулятор уборки

Публичная **нейтральная витрина** калькулятора FORMACLEAN. Это отдельный статический сайт, предназначенный для демонстрации интерфейса и выбора услуг.

- [Открыть `index.html` в репозитории](index.html)
- Исходные инструменты разработки и рабочие данные не публикуются в этом репозитории.
- Сайт работает без сервера: HTML, CSS и JavaScript находятся в одном `index.html`; внешних API, сборщиков, баз данных, передачи заявок и аналитики нет.
- Все цены и минимальные суммы **условные**. Сайт не является официальным сайтом клининговой компании. Уведомление находится в нижнем колонтитуле.
- Для локального просмотра скачайте `index.html` и откройте двойным щелчком в браузере.

## Включить GitHub Pages

1. Откройте [Settings → Pages](https://github.com/ddrmkd/cleaning-demo-showcase/settings/pages).
2. В **Build and deployment** выберите **Deploy from a branch**.
3. В Branch выберите **main**, директорию **/(root)** и нажмите **Save**.
4. После успешного развертывания адрес будет [https://ddrmkd.github.io/cleaning-demo-showcase/](https://ddrmkd.github.io/cleaning-demo-showcase/).

URL выше является **ожидаемым адресом**, а не подтверждением включённого GitHub Pages.

Не добавляйте сюда клиентские контакты, персональные данные, API-ключи или настоящие заявки.
